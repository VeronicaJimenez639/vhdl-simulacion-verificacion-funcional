# VHDL – Simulación y Verificación Funcional

Este repositorio contiene las prácticas desarrolladas en la Unidad IV de la asignatura Fundamentos de Sistemas Digitales, enfocadas en el diseño, simulación y verificación funcional de circuitos combinacionales en VHDL.

## Contenido

- Compuerta AND de dos entradas
- Sumador de 2 bits
- Multiplexor 2:1
- Decodificador 2 a 4
- Comparador de 2 bits
- Testbenches para cada circuito
- Archivos de simulación y formas de onda

## Herramientas utilizadas

- VHDL
- GHDL
- Surfer Waveform Viewer
- Visual Studio Code
